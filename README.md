# 跨境文旅数据协作

支持多国文旅资料标准互认、多语种发布和授权追踪。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括目的地文旅机构、景区与活动主办方、票务平台方、平台运营方、数字导览产品方、数字人服务方、跨境产品运营方和国际游客。

资料所依据的领域事实如下：

- 旅游展区聚集多个国家和地区的机构企业
- 合作方向包括数据互通和服务标准互认
- 多语种导览与数字化服务用于改善跨境旅行体验
- 同一景区的开放时间可能分别来自目的地机构、票务平台和旧宣传册且互相冲突
- 自动翻译可能曲解安全提醒，译文须经审核修订
- 合作覆盖五十六个国家和地区，人工群聊无法保证游客看到可靠版本

## 协作方式

平台由来源负责：来源机构提交景点、路线、文化说明、票务政策、签证提示和实时提醒，经对应机构审核通过后，导览、数字人和跨境产品才能按获授权的语言与渠道引用。标准字段改变、译文修订、临时闭园、授权到期、内容争议或来源撤回时，平台列出全部受影响产品并推动更新。

游客页面标明责任来源和更新时间，各机构保留对自己资料的控制权。运营方依据资料完整度推进标准互认，不能用访问量替代可信度。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、内容类型、事实、协作流程、变更事件和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
