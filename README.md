# 跨境文旅数据协作

支持多国文旅资料标准互认、多语种发布和授权追踪。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括目的地文旅机构、景区与活动主办方、数字导览产品方、国际游客。

资料所依据的领域事实如下：

- 旅游展区聚集多个国家和地区的机构企业
- 合作方向包括数据互通和服务标准互认
- 多语种导览与数字化服务用于改善跨境旅行体验

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
